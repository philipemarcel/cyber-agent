# CYBER//AGENT — prompts das artes

Ferramenta usada: `image_gen` embutida (`image_gen.imagegen`), sem CLI/API de fallback. Foram feitas três chamadas, uma por arte, em paralelo. Os prompts abaixo são os textos exatos enviados à ferramenta.

## nexus-hq.png

Sala-base isométrica de operações de cibersegurança à noite.

Caminho final: `public/art/nexus-hq.png`  
Parâmetro: `transparent_background: false`

```text
Use case: stylized-concept
Asset type: actual in-game hub background for CYBER//AGENT, a cybersecurity educational browser game.
Primary request: Create one original wide 16:9 illustration of an isometric cybersecurity operations office at night.
Style/medium: Authentic 16-bit SNES-era pixel art: deliberately visible crisp square pixels and cohesive pixel clusters; 2-3 tones per material; clean stepped silhouettes, no antialiasing or smooth gradients.
Scene/backdrop: A wide unobstructed isometric room with desks and CRT monitors, server racks, and blue city windows. One tiny worker sits at a desk. Cozy classroom and game-base feeling.
Color palette: Indigo and navy pixel tiles, mint and lime glowing monitor screens, violet accents. Limited harmonious palette.
Composition/framing: Full room fits within a wide 16:9 image; useful broad floor space and clear distinct furniture silhouettes. This is a real game environment, not a web page mockup.
Constraints: No text, letters, numbers, logos, UI, border, watermark, blur, photorealism, vector art, or 3D rendering. One final raster image only.
```

## mentor-agent.png

Mentora de corpo inteiro com cabelo violeta, headset e uniforme da academia.

Caminho final: `public/art/mentor-agent.png`  
Parâmetro: `transparent_background: true`

```text
Use case: stylized-concept
Asset type: single standalone character sprite for CYBER//AGENT cybersecurity educational browser game.
Primary request: One friendly adult agent mentor, full body, short violet hair, headset, indigo security academy jacket with mint accents, dark boots, facing slightly right, one hand on hip.
Style/medium: Authentic 16-bit SNES-era pixel art with deliberately visible crisp square pixels, clean stepped outlines, cohesive pixel clusters and 2-3 flat tones per material. Readable friendly expression.
Color palette: Indigo/navy, violet hair and accents, mint trim; same limited game palette.
Composition/framing: Single full-body sprite centered with generous transparent alpha margin on all sides. Proportions suitable for a small in-game character. No part cropped.
Background: Genuinely transparent alpha background. No ground plane, no cast shadow touching margins.
Constraints: No words, logos, UI, border, watermark, background, blur, antialiasing, smooth gradients, photorealism, vector art, 3D rendering, duplicate character or sprite sheet. One final raster image only.
```

```text
Asset type: single standalone small robot assistant sprite for CYBER//AGENT cybersecurity educational browser game.

Style/medium: Authentic 16-bit SNES-era pixel art with deliberately visible crisp square pixels, clean stepped outline, cohesive pixel clusters and 2-3 flat tones per material.
Color palette: Indigo/navy casing, violet accents, mint/cyan screen; harmonious limited palette matching a pixel cybersecurity game.
Composition/framing: Single sprite centered with generous transparent alpha margin on all sides, whole robot visible, readable at small sizes.
Background: Genuinely transparent alpha background; no ground or background scene.
Constraints: No text, words, logos, UI, border, watermark, background, blur, antialiasing, smooth gradients, photorealism, vector art, 3D rendering, duplicate drone or sprite sheet. One final raster image only.
```
